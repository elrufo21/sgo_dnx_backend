# Permisos fijos de usuarios

Mantenimiento envía `1` para envío de boleta, factura, nota de crédito y nota de débito. Los usuarios nuevos se crean con `Administrador = 0`; al editar, el repositorio consulta y conserva el indicador actual en la base. No se modifican automáticamente los usuarios existentes ni se permite elevar el indicador mediante este formulario. Los administradores existentes conservan acceso total; su revisión requiere intervención autorizada.
