# SGO DXN Capture para Firefox — COMAS

Destino SGO: http://192.168.18.47:8080
OBS: https://obs6.dxn2u.com

## Instalación temporal para probar

1. Abre Firefox y visita bout:debugging#/runtime/this-firefox.
2. Pulsa **Cargar complemento temporal...**.
3. Selecciona el archivo .xpi de este paquete.

La instalación temporal se elimina al cerrar Firefox. Para una instalación permanente, Mozilla debe firmar el complemento (por AMO o distribución empresarial firmada).

## Uso

1. Abre una venta o resumen en OBS.
2. Pulsa **Enviar a SGO** o **Enviar resumen a SGO**.
3. La extensión abrirá o enfocará el formulario SGO de este destino.

El complemento lee datos visibles de la venta/resumen (incluidos nombre/correo/código de miembro y datos de transacción) y los transfiere a la aplicación SGO de la empresa indicada arriba.

La variante de Chrome/Brave no se modifica. No mezclar el paquete COMAS con ICA.
