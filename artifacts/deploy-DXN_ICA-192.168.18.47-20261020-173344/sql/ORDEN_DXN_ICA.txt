ACTUALIZACION INCREMENTAL PARA DXN_ICA - 2026-10-20
====================================================

Destino: base DXN_ICA. Scripts compatibles con SQL Server 2008 R2.
La aplicacion no ejecuta estos scripts automaticamente. No fueron ejecutados
contra DXN_ICA al preparar este paquete.

Antes de aplicar: el responsable de SQL debe verificar la base seleccionada,
respaldar la base y confirmar si cada cambio ya existe. Ejecutar los scripts
por separado, en este orden:

1. 20261020_fix_uspListaDocumentosWEB_excluir_hoy.sql
   Actualiza solo dbo.uspListaDocumentosWEB; excluye las boletas del dia actual
   del resumen normal. No cambia filas de documentos.

2. 20261020_usp_Maquina_permitir_series_repetidas.sql
   Actualiza solo dbo.usp_Maquina; permite reutilizar series entre maquinas y
   conserva la validacion del nombre de maquina. No cambia filas de maquinas.

3. 20261020_maquinas_permitir_impresora_repetida.sql
   Quita solo una restriccion o indice UNIQUE de una sola columna sobre
   dbo.MAQUINAS.Tiketera, si existe. No elimina filas. Si no existe, no cambia
   la estructura.

4. 20261020_normalizar_indicadores_configuracion.sql
   Actualiza solo los metadatos Area, TipoIndicador e IdIndicador de las claves
   de configuracion conocidas. No borra ni inserta filas permanentes en
   dbo.Indicador, y conserva ValorTexto1, ValorNum y ValorDecimal.

   El script valida duplicados y referencias antes de abrir la transaccion. Si
   encuentra ambiguedades, se detiene sin actualizar; no elige ni borra filas.
   Revisar el resultado con el responsable de SQL antes de resolver cualquier
   duplicado manualmente.

No ejecutar junto con este paquete los scripts de instalacion completa,
migracion historica o configuracion inicial: esta entrega contiene solo parches
incrementales para actualizar una base existente.
